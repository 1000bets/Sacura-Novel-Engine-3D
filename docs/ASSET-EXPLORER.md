# Нативный «Проводник»

Перенос `AssetExplorer.jsx` / `assetExplorer.css` в Qt, 22 октября 2026.

Вкладка «Проводник» доступна в нижнем доке и в меню окон. Сохранённая раскладка
пользователя сохраняет приоритет. Панель содержит дерево Assets и ресурсов
движка, кликабельный путь, поиск, кнопки создания папки и импорта файлов/папки,
плитки с типами ресурсов, подсказку перетаскивания и сведения о выделении.
При ширине менее 820 логических пикселей панель инструментов занимает две
строки; менее 560 — кнопки сохраняют иконки, подсказки и доступные имена.

Поиск без учёта регистра включает вложенные ресурсы и папки текущего уровня.
Меню справа в поле поиска строится из зарегистрированных типов ресурсов;
фильтр типа включает ресурсы во вложенных папках. Навигация очищает поиск,
синхронизирует выделение дерева и сохраняет пользовательское раскрытие веток.
Открытие двойным щелчком использует прежний контракт идентичности ресурса.
Существующие переименование, удаление, перемещение и буфер обмена сохранены.

Импорт файлов и внешнее перетаскивание папки проходят через один предпросмотр.
Поддерживаются самодостаточный GLB, статический FBX, PNG и JPEG. Вложенные
каталоги сохраняются, FBX преобразуется в GLB. Размер каждого файла ограничен
100 МиБ; превышение обнаруживается до открытия предпросмотра. Неподдерживаемые
файлы пропускаются с указанием числа в диалоге, ссылки не обходятся. Отмена
предпросмотра ничего не записывает. Импорт публикует уведомление об изменении
ресурсов, чтобы остальные панели обновили доступные ресурсы.

Представление (`AssetExplorerView`), отрисовка плитки (`AssetExplorerStyle`) и
сбор файлов (`AssetImportSources`) находятся в Editor/UI. `ContentBrowserWidget`
связывает их с существующими `AssetRegistry`, `AssetImporter`, `AssetOperations`.
Цвета и иконки общие с остальным редактором; QSS хранится в `explorer.qss`.
Форматы авторских данных и идентичность ресурсов не изменены.

Продуктовые принципы:

- Простота: папка → импорт → просмотр состава → подтверждение; поиск и
  переходы не требуют ручного ввода ID или JSON.
- Переносимость и редактируемость: используется прежний локальный импорт
  ресурсов и `.meta`. Перенос пакетов механик A → B → C не относится к этой
  панели и не объявляется проверенным этим изменением.
- Универсальность: список типов приходит из реестра; нет зависимости от
  персонажа, боя или жанра проекта.

Ограничения: аудиофайлы и произвольные файлы веб-прототипа не получают новый
нативный загрузчик этим изменением. Импорт не создаёт пустые каталоги или
каталоги только с неподдерживаемыми файлами. Существующий AssetImporter
публикует файлы по отдельности: ошибка позднего файла не отменяет уже
импортированные; итоговый диалог перечисляет ошибки. Это импорт ресурсов,
не атомарный импорт пакета авторской логики. Плитки используют типовые иконки,
без предпросмотра текстур. Проверка композитора рабочего стола не выполняется.

В Windows runtime helper встраивает `WindowsUtf8.manifest` в исполняемые
файлы, включая Editor, Player и тесты. Это согласует UTF-8 путей Qt/JSON с
узкими файловыми API процесса и устраняет ошибку обхода каталогов с кириллицей.
Системные настройки кодировки не меняются. Механизм требует Windows 10 1903+
([документация Microsoft](https://learn.microsoft.com/en-us/windows/apps/design/globalizing/use-utf8-code-page));
на более старой Windows поддержка таких путей этим изменением не гарантируется.

## Фактическая проверка

- `Editor`, `SakuraEditor`, `SakuraPlayer` и локальные тестовые исполняемые
  файлы собраны в Debug с готовыми зависимостями. Финальная сборка использует
  `BuildProjectReferences=false`, чтобы не пересобирать общие библиотеки
  одновременно с соседними задачами. Логи: `build/explorer-focused-build.log`
  и `build/explorer-final-build.log`. SHA256 Editor в `Root/Debug` и `Stage/Bin`
  совпадает после сборки.
- `Editor.AssetExplorer` прошёл при масштабе 100%, 125% и 200%. Проверены
  поиск папок и вложенных ресурсов без учёта регистра, синхронизация дерева и
  пути, зарегистрированные фильтры, сигнал открытия с ID и типом, выделение,
  пустой результат, компактный док, запрет импорта в Engine, создание папки
  с кириллицей, импорт вложенной папки и файла с кириллицей через настоящий
  Qt drop/предпросмотр, `.meta`, отмена и лимит 100 МиБ. Тесты локальные,
  gitignored, как требует проект.
- `Editor.UI.Foundation` прошёл. `Editor.Story.Graph.Shell` не прошёл:
  `Graph undo modified scene history` после переноса вкладки истории.
  Это незакрытый результат общей проверки; исправность всего shell не заявляется.
  Лог: `build/explorer-regression.log`.
- Qt-снимки широкой панели и дока шириной 480 логических пикселей просмотрены:
  `build/explorer-captures/`, `build/explorer-captures-125/` и
  `build/explorer-captures-200/`. Computer Use не применялся.
- `Scripts/VerifyEditorUiSources.py` прошёл (52 общих токена палитры,
  отсутствие inline-стилей в UI/Shell). `git diff --check` затронутых
  tracked-файлов прошёл.
