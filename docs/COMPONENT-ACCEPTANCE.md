## Проверенная цепочка автора

В браузере на отдельном локальном origin созданы пустые проекты «Интеграция ·
Relay A/B/C». Через **Создать новое определение → Код** написаны
`AcceptanceLedger` и отсутствующий во всех шаблонах `ThresholdRelay`:
параметры factor/threshold/delay, состояние total/initializations, метод
apply(amount) → number, условие порога, вызов конкретного Ledger.record и сигнал accepted.
Параметры и ссылка выбраны в инспекторе; вызов до текста — через выбор
владельца, подключения, метода и числового аргумента. JSON проекта и ручные ID
не использовались. В A результат 9, после сохранения/загрузки total=9 и
initializations=1; второй экземпляр имеет total=0 и свою настройку factor=5.
Переименование владельца сохраняет вызов.

Экспорт A через **Экспортировать компонент** с выбранным подключением сам
добавил транзитивный Ledger: 2 определения, 2 исходника, 2 подключения, 3 метода.
Внешний вход назван «Приёмник». B импортировал с выбором своего объекта,
исходники открыты/сохранены для запуска; формула изменена на `amount * factor + 4`.
B дал 13 и экспортирован повторно с сохранением происхождения A и лицензии CC0.
В C сначала отменён подготовленный импорт (никаких добавлений), затем применён
пакет B с новой привязкой. C дал 13 в Play и скачанном из меню отдельном HTML;
повторный запуск A по-прежнему дал 9. Во время экспорта Play-состояние не стало defaults.

Доказательства: [автономный C](screenshots/component-acceptance-relay-C.png),
[ошибка конкретного получателя](screenshots/component-acceptance-error.png).
В C намеренно добавлен throw в Ledger.record: панель указала **Приёмник C →
AcceptanceLedger → Записать**, путь и строку, остановила Play и открыла именно
record. Текст сохранился. После исправления следующий запуск снова дал 13.

## Исправленные интеграционные дефекты

- Доставленная реакция получателя ошибочно наследовала отменяемый native Event
  издателя. Регрессионный тест сначала воспроизвёл сбой; реакция теперь имеет своего владельца.
- Вложенная JS-ошибка теряла идентичность получателя, а внешний вызов добавлял
  чужой путь с номером строки внутреннего исходника. Сохранены реальный Error,
  цепочка и переход к конкретному компоненту/методу.
- Дубликат объекта копировал геометрию, оставляя взаимодействие на оригинале.
  Теперь копируются конфигурации подключений и native adapters, внутренние ссылки
  переназначаются в два прохода, определения не размножаются. Вставка использует
  снимок буфера, а не текущее выделение. Межпроектный перенос — через пакет.
- В standalone без HUD сообщения SDK не показывались во время диалога; стили
  обратной связи зависели от editor CSS. Исправлены player и общий CSS.
- Граф компонента имел нулевую высоту из-за size containment родительской
  рабочей области: порты были в DOM, но клики попадали в журнал. Задана
  минимальная высота/размер flex; соединение портов проверено в браузере.
- Из JS не было перехода к вызываемому графу, а стабильный ID графового метода
  приходилось искать вручную. Добавлены статическая навигация по вызовам и
  копирование SDK-вызова выбранного метода. Просмотр не исполняет код.
- Узел данных BT создавал скрытый state.value, хотя селектор показывал другую
  переменную. Теперь выбирается реально объявленное поле; при отсутствии полей
  создание объясняет причину отказа. Задачи подписываются выбранным методом.
- В новом шаблоне явные переходы обходили merge1/l4/merge4. Генератор ведёт
  lh3 → merge1 → l4 и ch2 → merge4; исправленные реплики реально посещены.
  Старый fixture совместимости не менялся, публичный пакет пересобран.
- Добавлены видимый импорт и save/load в Play; заголовок вкладки показывает текущий проект.
- В процессе работы собственная ошибка обращения к пустому preview была поймана
  в браузере и исправлена на optional access; финальный прогон включает исправление.

Последние две frontend-команды создают `dist/examples/` и `dist/acceptance/`.

редактируемость** — ручной A → B → C и отдельный составной автоматический цикл;
**универсальность** — те же вызовы для двери, награды, UI, истории и боя, новый
Relay работает в пустом проекте без героя/HP/оружия.
