# Редактор виджетов React

Откройте кнопку «Редактор интерфейса игры» над сценой либо панель «Виджеты UI» в меню «Окна». Создайте виджет и откройте его из списка. Виджеты также создаются и открываются двойным щелчком в Content Browser.

Редактор использует холст и инспектор веб-прототипа: панели, текст, кнопки, изображения, варианты ответа, шкалы и инвентарь; иерархию элементов; анкеры и pivot; перемещение и изменение размеров; порядок отрисовки; CSS виджета. Выбор разрешения влияет только на предпросмотр. Кнопка «Предпросмотр» показывает макет и позволяет проверить нажатия без выполнения игровых команд.

## Хранение

Рекомендуемый путь — `Content/UI/Interface.widget`. Создание из панели UI использует эту папку; Content Browser сохраняет выбранную подпапку. Виджет является ассетом `Widget`, его `.meta` содержит стабильный GUID. Переименование файла не меняет идентичность виджета.

Формат JSON — `sakura.widget`, версия 1. Документ содержит поля `format`, `version` и один объект `widget` с `id`, `name`, `kind`, `referenceSize`, `elements`, `css`. Один файл содержит ровно один макет, без списка виджетов и назначений по умолчанию.

Окно Widget UI перечисляет ассеты и ищет по имени и пути. Выбор открывает обычную вкладку документа; повторное открытие выбирает существующую вкладку с её историей. В редакторе доступны элементы одного виджета, его тип и предпросмотр. Создание другого виджета выполняется через список или Content Browser.

ID элемента уникален внутри виджета. `parentId` ссылается на локальную панель; циклы запрещены. `imageAssetId` содержит GUID текстуры из Content. Неизвестные дополнительные поля документа сохраняются. Для переноса нужны `.widget`, его `.meta` и используемые текстуры с их `.meta`. Экспорт игры переносит их вместе с Content.

Ограничения: 512 КиБ на документ, до 512 элементов. Размер эталонного холста — от 100 до 7680 пикселей по каждой оси.

## Сохранение и команды

Правки остаются в документе до «Сохранить» или Ctrl+S. История независима от истории сцены. Один жест перемещения создаёт один шаг Undo. Закрытие вкладки с правками использует обычный запрос сохранения. Сохранение проекта также сохраняет открытые изменённые документы, которыми владеет соответствующая нативная сессия.

Редактор и MCP используют `assetDocument.execute` с `assetId`, операцией и актуальным `revision`. Поддержаны `open`, `get`, `edit`, `undo`, `redo`, `save`, `reload`; `edit.value` содержит полный документ. Ревизия из последнего ответа обязательна для изменений. Несохранённый документ нельзя перечитать. Внешнее изменение файла блокирует перезапись; черновик остаётся доступным. Engine Content и Play доступны только для чтения. Создание использует фабрику `editor.CreateWidgetAssetFactory` через `assets.create`; при прямом вызове команды папку сначала создают через `assets.createFolder`.

Навигация по холсту, выделение и предпросмотр не изменяют документ и не требуют отдельных MCP-команд.

## Подключение к игре

Опубликованный Python-метод `GetGameView()` может добавить в возвращаемый JSON:

```json
{
  "widgetAssets": {"hud": "GUID ассета HUD", "dialogue": "GUID ассета диалога"},
  "variables": {"hp": 73, "maxHp": 100},
  "actions": [{"id": "heal", "label": "Лечение", "enabled": true}]
}
```

Нативный хост читает сохранённые виджеты по GUID, проверяет соответствие kind назначенной роли и передаёт HUD, диалог и меню в существующий React Player. Данные Python по-прежнему ограничены 64 КиБ; макеты добавляются хостом после этого. Изображения загружаются штатным загрузчиком текстур, для передачи в React ограничиваются 512 пикселями по стороне. Полноразмерные текстуры остаются в Content. Общий разрешённый объём игровых UI-представлений — 6 МиБ.

В поле привязки элемента укажите путь в `variables`, например `hp`, а в формате текста — `HP: {value}`. Для игровой кнопки выберите действие «Игровая команда» и укажите `heal` как идентификатор опубликованного действия. Исполнение проходит через `game.action` и существующий `ExecuteGameAction`; неизвестные, отключённые и недопустимые на паузе действия отклоняются нативным кодом. Для выполнения на паузе опубликованное действие должно иметь `allowWhilePaused: true`.

Нативная версия не предлагает неподключённые события и компоненты веб-прототипа. Уже существующие проекты, возвращающие готовые `widget`/`widgets` из Python, продолжают работать без изменений. Их макеты не переносятся в новые ассеты автоматически.

## Проверки

`desktop-electron/tests/widget-asset.test.cjs` проверяет фабрику, историю, явное сохранение, конфликты, повторное открытие, запрет изменений в Play и независимость документов и использование отдельных виджетов игровым представлением.

`desktop-electron/scripts/widget-editor-check.cjs` запускается приложением с параметром `--widget-editor-check=<абсолютный путь PNG>`. Проверяет создание через интерфейс, отсоединённое окно, реальный жест мышью, Undo/Redo, сохранение, добавление элемента, предпросмотр, повторное открытие и узкую раскладку. Тестовые проекты и профили должны находиться на диске проекта, вне пользовательского Content.
