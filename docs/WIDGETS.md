# Редактор виджетов React

Откройте кнопку «Редактор интерфейса игры» над сценой либо панель «Виджеты UI» в меню «Окна». Создайте библиотеку и откройте её из списка. Библиотеки также создаются и открываются двойным щелчком в Content Browser.

Редактор использует холст и инспектор веб-прототипа: панели, текст, кнопки, изображения, варианты ответа, шкалы и инвентарь; иерархию элементов; анкеры и pivot; перемещение и изменение размеров; порядок отрисовки; CSS виджета. Выбор разрешения влияет только на предпросмотр. Кнопка «Предпросмотр» показывает макет и позволяет проверить нажатия без выполнения игровых команд.

## Хранение

Рекомендуемый путь — `Content/UI/Interface.widgets`. Создание из панели UI использует эту папку; Content Browser сохраняет выбранную подпапку. Библиотека является ассетом `WidgetLibrary`, её `.meta` содержит стабильный GUID. Переименование файла не меняет идентичность библиотеки.

Формат JSON — `sakura.widgets`, версия 1. Поля:

| Поле | Значение |
|---|---|
| `format` | `sakura.widgets` |
| `version` | `1` |
| `widgets` | Массив макетов из прототипа: `id`, `name`, `kind`, `referenceSize`, `elements`, `css` |
| `ui` | Назначения по умолчанию для `dialogue`, `hud`, `mainMenu`, `pauseMenu` |

ID виджета уникален внутри библиотеки, ID элемента — внутри виджета. `parentId` ссылается на локальную панель; циклы запрещены. `imageAssetId` содержит GUID текстуры из Content. В библиотеке не сохраняются абсолютные пути, размеры окна редактора, выделение или масштаб предпросмотра. Неизвестные дополнительные поля документа сохраняются.

Каждый файл содержит собственные назначения по умолчанию. Несколько библиотек могут сосуществовать: движок не выбирает первую найденную автоматически. Для переноса библиотеки с изображениями нужно перенести `.widgets`, его `.meta`, текстуры и их `.meta`. Обычный экспорт игры уже переносит весь Content, включая эти файлы.

Ограничения: 512 КиБ на документ, до 128 виджетов и до 512 элементов в одном виджете. Размер эталонного холста — от 100 до 7680 пикселей по каждой оси.

## Сохранение и команды

Правки остаются в документе до «Сохранить» или Ctrl+S. История независима от истории сцены. Один жест перемещения создаёт один шаг Undo. Закрытие вкладки с правками использует обычный запрос сохранения. Сохранение проекта также сохраняет открытые изменённые документы, которыми владеет соответствующая нативная сессия.

Редактор и MCP используют `assetDocument.execute` с `assetId`, операцией и актуальным `revision`. Поддержаны `open`, `get`, `edit`, `undo`, `redo`, `save`, `reload`; `edit.value` содержит полный документ. Ревизия из последнего ответа обязательна для изменений. Несохранённый документ нельзя перечитать. Внешнее изменение файла блокирует перезапись; черновик остаётся доступным. Engine Content и Play доступны только для чтения. Создание использует фабрику `editor.CreateWidgetLibraryAssetFactory` через `assets.create`; при прямом вызове команды папку сначала создают через `assets.createFolder`.

Навигация по холсту, выделение и предпросмотр не изменяют документ и не требуют отдельных MCP-команд.

## Подключение к игре

Опубликованный Python-метод `GetGameView()` может добавить в возвращаемый JSON:

```json
{
  "widgetLibrary": "GUID ассета библиотеки",
  "variables": {"hp": 73, "maxHp": 100},
  "actions": [{"id": "heal", "label": "Лечение", "enabled": true}]
}
```

Нативный хост читает сохранённую библиотеку по GUID и передаёт выбранные HUD, диалог и меню в существующий React Player. Данные Python по-прежнему ограничены 64 КиБ; макеты добавляются хостом после этого. Изображения загружаются штатным загрузчиком текстур, для передачи в React ограничиваются 512 пикселями по стороне. Полноразмерные текстуры остаются в Content. Общий разрешённый объём игровых UI-представлений — 6 МиБ.

В поле привязки элемента укажите путь в `variables`, например `hp`, а в формате текста — `HP: {value}`. Для игровой кнопки выберите действие «Игровая команда» и укажите `heal` как идентификатор опубликованного действия. Исполнение проходит через `game.action` и существующий `ExecuteGameAction`; неизвестные, отключённые и недопустимые на паузе действия отклоняются нативным кодом. Для выполнения на паузе опубликованное действие должно иметь `allowWhilePaused: true`.

Нативная версия не предлагает неподключённые события и компоненты веб-прототипа. Уже существующие проекты, возвращающие готовые `widget`/`widgets` из Python, продолжают работать без изменений. Их макеты не переносятся в новые библиотеки автоматически.

## Проверки

`desktop-electron/tests/widget-library.test.cjs` проверяет фабрику, историю, явное сохранение, конфликты, повторное открытие, запрет изменений в Play и использование библиотеки игровым представлением.

`desktop-electron/scripts/widget-editor-check.cjs` запускается приложением с параметром `--widget-editor-check=<абсолютный путь PNG>`. Проверяет создание через интерфейс, отсоединённое окно, реальный жест мышью, Undo/Redo, сохранение, добавление элемента, предпросмотр, повторное открытие и узкую раскладку. Тестовые проекты и профили должны находиться на диске проекта, вне пользовательского Content.
