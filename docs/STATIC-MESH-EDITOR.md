# Редактор Static Mesh

Двойной щелчок по StaticMesh в Content Browser открывает отдельное окно с нативным предпросмотром. Открытие Model выбирает первый StaticMesh; остальные меши открываются через подассеты модели.

Материалы назначаются существующим слотам меша. Приоритет: динамический материал слота, материал слота экземпляра, материал меша. Общий материал экземпляра заменяет материалы меша, сохраняя явные переопределения отдельных слотов. Доступны только Surface Material и MaterialInstance.

Коллизия задаётся отдельно для каждого меша как набор элементов. Элементы можно добавлять, выбирать, дублировать и удалять. У каждого элемента есть форма Box / Sphere / Capsule / Triangle Mesh, центр, поворот по трём осям в градусах, полуразмеры, радиус и половина высоты цилиндрической части капсулы. Кнопка подгонки использует границы меша и сбрасывает поворот выбранного элемента. Предпросмотр показывает контуры всего набора. Физика прикрепляет все формы к одному телу: они движутся вместе, а события контактов агрегируются по телам. Геометрия навигации и отладки включает все элементы.

Triangle Mesh предназначен для Static / Kinematic и не поддерживает trigger. При динамическом теле все элементы должны быть примитивами. Повернутые Box / Capsule требуют положительного равномерного масштаба объекта: неравномерный масштаб повернутого примитива создаёт сдвиговую деформацию, которую эти формы PhysX не представляют. Для треугольников поворот и масштаб запекаются в вершины. CharacterController использует собственную капсулу и не поддерживает составной набор.

Сохранение явное, в `.meta` исходной модели: `loadSettings.staticMeshDefaults.<subasset GUID>`. Геометрия GLB не переписывается. Undo/Redo относится к документу настроек. Изменение метаданных другим процессом блокирует сохранение до перечитывания; остальные поля метаданных сохраняются. Engine Content доступен для просмотра.

Новые объекты, размещённые из Content Browser в основную сцену или prefab, получают PhysicsBody с `use_mesh_defaults=true`, если сохранённая коллизия меша включена. Это обычная операция истории сцены. Существующий PhysicsBody можно переключить тем же свойством: геометрия и включение коллизии берутся из меша; движение, масса, трение и фильтры остаются у тела. Если тела нет, добавьте PhysicsBody и включите свойство. Сохранение настроек меша не добавляет компоненты существующим объектам автоматически. Материалы меша применяются и к существующим экземплярам без переопределений.

## Console / MCP

`static_mesh_document` использует тот же открытый документ, поля и историю, что окно редактора:

- `path`: виртуальный путь модели, например `/Game/Meshes/House.glb`.
- `subAssetId`: GUID меша; без него выбирается первый StaticMesh модели.
- `operation`: `inspect`, `edit`, `undo`, `redo`, `reload`, `save`.
- `defaults`: полный объект настроек для `edit`; структуру возвращает `inspect` в поле `defaults`.

`materials` — массив `{slot, material: {assetId, subAssetId}}`; `collision` — объект с `enabled` и массивом `elements`. Каждый элемент содержит `shape` (0–3), `center`, `rotation` (XYZ в градусах), `halfExtents` (три числа), `radius`, `capsuleHalfHeight`. Старый одиночный формат без `elements` читается как один элемент. Включённая коллизия требует хотя бы одного элемента; удаление последнего выключает её. Удаление записи слота возвращает отсутствие материала по умолчанию. Изменения, Undo/Redo, перечитывание и сохранение запрещены во время Play. Управление камерой и показом контуров являются только UI-настройками предпросмотра.

Проверки: `Editor.StaticMesh`; нативный прогон `SakuraStaticMeshEditorTest --render` создаёт снимок окна в рабочем каталоге теста. Он проверяет реальную загрузку ресурсов и render snapshot материала. Тестовые проекты создаются на диске рабочего каталога, а не в системном temp.


## Редактирование в локальной сцене

Во вкладке «Коллизия» выберите форму в списке или щелчком по ней в сцене.
Выбранная форма выделяется оранжевым, остальные — голубым. Кнопка «Добавить»
сразу предлагает тип формы. Числовые параметры показываются только для её типа;
материалы находятся в отдельной вкладке.

- W — перемещение, E — поворот, R — размер, Q — выбор. Инструменты также доступны кнопками.
- Перетаскивание гизмо меняет предпросмотр; отпускание мыши записывает один шаг Undo.
- ПКМ и WASD/QE — свободная камера; Alt + ЛКМ — орбита; СКМ — сдвиг; колесо — приближение.
- «Меш целиком» / Home возвращает камеру к мешу; «Выбранная форма» / F кадрирует коллизию.
- Ctrl+Z / Ctrl+Y и MCP используют ту же историю документа. Сохранение остаётся явным.

Видимость форм независима от «Коллизия по умолчанию»: выключенные физические
формы остаются доступными для редактирования. «Показать коллизию» управляет только
предпросмотром. Линии обрезаются по границам объёма камеры, включая ближнюю
плоскость, вместо исчезновения всего ребра. Выбор мышью использует геометрию форм,
а не объекты основной сцены. Камера, выбор и видимость — UI-only; изменения
положения, поворота и размеров доступны через существующий `static_mesh_document`.

Размер сферы меняет радиус, капсулы — радиус и половину высоты цилиндра.
Треугольная коллизия повторяет исходную геометрию: гизмо поддерживает перемещение
и поворот; отдельного масштаба треугольной формы в формате нет.
