# Базовые фигуры

В Content Browser откройте Engine → BasicShapes и перетащите фигуру в сцену.
Двойной щелчок открывает её в редакторе Static Mesh. Встроенные ресурсы доступны
для просмотра; материал и физические параметры экземпляра меняются в Inspector.

| Ресурс | Размеры, метры | Коллизия по умолчанию |
|---|---|---|
| Cube | 1 × 1 × 1 | Box |
| Sphere | Диаметр 1 | Sphere |
| Capsule | Диаметр 1, полная высота 2 | Capsule |
| Cylinder | Диаметр 1, высота 1 | TriangleMesh |
| Cone | Диаметр основания 1, высота 1 | TriangleMesh |
| Plane | 1 × 1 в плоскости XZ, нормаль +Y | Box толщиной 0,01 под поверхностью |

Начало координат находится в центре фигуры. Вертикальная ось — Y.
У каждой фигуры есть нормали, UV-развёртка и слот 0 с Engine StandardPBR.
Цилиндр и конус используют точную треугольную коллизию: она рассчитана на
Static/Kinematic. Для динамического тела замените коллизию экземпляра подходящими
примитивами, отключив `Use Static Mesh Collision Defaults`.

Ресурсы — обычные GLB с постоянными идентификаторами в `.meta`, а не специальные
типы объектов. Они используют существующие загрузку, размещение, Undo и инструменты
MCP для ресурсов и компонентов. Отдельные команды для фигур не требуются.
Engine Content включается в установленный редактор и экспорт игры существующим
механизмом развёртывания. Это не проверка переноса авторских пакетов A → B → C.

Исходный генератор: `Scripts/GenerateBasicShapes.py`. Он воспроизводит геометрию,
идентификаторы и контрольные суммы без сторонних Python-пакетов.
