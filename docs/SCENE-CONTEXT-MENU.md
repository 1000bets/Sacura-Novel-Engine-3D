# Контекстное меню сцены

Правый клик в Edit viewport открывает «Сцена»: поиск, разделы «Добавить объект»,
«Выделение», «Вид», иконки и вложенные меню по образцу `Editor.jsx`.
Перетаскивание ПКМ, Alt-навигация и движение камерой с клавиатуры не открывают
меню. Поиск включает вложенные команды и сохраняет их доступность.

Работают пустой объект, статический меш, точечный свет, точка постановки,
камера из текущего вида, кадрирование (F), дублирование, удаление (Del),
мировые/локальные оси и сетка. Сетка синхронизирована с кнопкой viewport.
Камера получает положение, ориентацию, FOV и плоскости отсечения текущего вида;
если основная камера уже есть, новая не перехватывает её роль.

Точка постановки — обычный сериализуемый объект с ArrowComponent. Положение
вычисляется пересечением луча курсора с землёй Y=0; над горизонтом используется
плоскость глубины фокуса. Это не привязка к поверхности произвольного меша.
Маркер можно выбрать как объектную цель существующих действий истории.

Создание подготовлено вне документа и применяется одной командой вставки
поддерева. Дублирование и кадрирование разделяют реализацию с инспектором.
Команды захватывают идентичность сцены и выделения; Play и смена документа
закрывают меню. Callback повторно проверяет доступность перед изменением.

Оформление использует `StudioActionMenu`, `StudioMenuItem`, общие иконки,
палитры и `ActionMenuStyle`; в описании строки добавлена подпись горячей
клавиши. Разметка иконок и стили в shell не дублируются.

## Ограничения

Шаблоны персонажа и интерактивного предмета, звуковые события и готовые
геометрические примитивы веб-прототипа не перенесены в нативную модель.
Пункты показаны недоступными с пояснениями. Статическому мешу нужно выбрать
импортированный ресурс в инспекторе. Группировка недоступна при текущем
одиночном выделении. Совпадение списка меню не означает перенос исполнения
всех возможностей веб-прототипа.

## Продуктовые принципы

- Простота: правый клик → поиск → команда; параметры обычных объектов
  доступны в существующем инспекторе, без JSON или ручного ввода ID.
- Переносимость и редактируемость: используются прежние scene-компоненты,
  сериализация и история команд. Новый формат данных не введён. Пакеты
  механик и приёмка «Дверь с ключом» A → B → C этим изменением не затронуты.
- Универсальность: меню работает с обычной сценой, объектами, камерой и светом;
  герой, боевые параметры и жанровая структура не требуются.

Локальный сценарий проверки: `Root/Tests/SceneMenuTest.cpp`
(`Editor.Scene.ContextMenu`). Тесты остаются gitignored согласно AGENTS.md.
