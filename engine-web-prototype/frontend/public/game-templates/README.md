# Учебные проекты на компонентах

Поставляются шесть редактируемых проектов в `sacura-authoring-package@3` и пакет
Reward + Counter. Каталог — `src/builtinTemplates.js`; четыре основные карточки,
UI-кликер в сворачиваемом разделе «Ещё» и featured-проект «Письма после дождя».

| Проект | Где открыть реальное поведение | Упражнение |
| --- | --- | --- |
| shooter | Боец/враг → Health, Weapon, Medkit, EnemyAgent/EnemyBehavior, DeathReaction; сцена → Battle/Objective | Изменить формулу урона, расход патронов или реакцию chase |
| point-and-click | Две двери → общий LockedDoor; ключ → Pickup | Потребовать два ключа вместо одного |
| novel | Отношение → Reward/Counter | Изменить награду за ответ; сравнить live binding со снимком |
| ui-clicker | Экономика кликера → Reward/Counter/PeriodicReward | Изменить формулу кнопки, улучшение и остановить собственный таймер |
| horror · Последний обход | Сцена → HauntedRoom; предмет → HauntedProp; выход → LockedDoor | Изменить условие escape или реакцию mirror; WASD и ПКМ + мышь, щелчок по предмету рядом |
| letters-after-rain | Алиса → Reward; письмо/шкатулка/записка/билет → StoryFlag; дверь → LockedDoor | Изменить действие осмотра и доступность чтения письма |

Путь: **Иерархия → объект → подключение → Открыть общую реализацию**.
Свой тип создаётся через **Создать → Компонент** без готовой механики. Исходники
в `templates/components/*.js` — та же программа, которую исполняет SDK в Play.
Параметры экземпляра меняются в инспекторе, реализация открывается в центре.
Пояснения доступны в проекте: «Игровые механики → Разбор проекта и упражнения».

`reward.sacura-package.json` содержит общие определения Reward + Counter.
В существующем проекте импортируйте пакет через «Игровые механики → Импортировать пакет», проверьте
состав, примените, откройте и сохраните исходники. Добавьте экземпляры и назначьте
конкретный Counter в ссылках Reward. Одинаковая формула используется для очков,
монет и отношения; исходники доступны для изменения и повторного экспорта.
Импорт и просмотр не запускают gameplay или установочные скрипты.

Генерация:

```sh
npm run build:templates
npm test
npm run build
node scripts/export-template-players.mjs
```

`build:templates` обновляет bundle исходников, шесть публичных проектов, reward
и media manifest. `templates/projects.mjs` строит пять проектов (хоррор использует
`templates/horror.mjs`);
`src/standardProjectComponents.js` добавляет компоненты featured-проекту.
HTML в `dist/examples/` содержат player, исходники и медиа. Они работают без
редактора и исходного проекта. Следующая build очищает dist; экспорт повторяется.
`node scripts/build-component-acceptance.mjs` создаёт отдельные изменённые
варианты для проверки правил в `dist/acceptance`, не заменяя публичные примеры.

`asset-manifest.json` позволяет встроенным примерам использовать установленные
медиа в редакторе без второй base64-копии в localStorage. Пакет и автономный
HTML содержат сами файлы. Обычный сторонний импорт не использует этот manifest.

Старые `sacura-project-template@1`, data-only пакеты v1/v2 и проекты gameplay v1
читаются через прежние адаптеры. Специальные fixtures в tests/fixtures не
переписываются и не являются исходниками новых шаблонов.
