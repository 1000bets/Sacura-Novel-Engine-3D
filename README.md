# Sacura-Novel-Engine-3D
Engine for creacting 3d visual novels

В предпросмотре диалогов камера чередует средние и крупные планы говорящего с общими планами рассказчика и выбора. Переходы сглажены; внутри реплики камера выполняет один небольшой проезд за 9 секунд. Пауза останавливает и движение, и его таймер. Автоматическая постановка применяется к штатному ракурсу: изменённая основная камера, явно выбранные камеры и осмотр предметов сохраняют приоритет.

Музыка под голосом плавно приглушается на −4 dB: attack 0,6 с, release 0,9 с. Единые настройки находятся в `ui template/src/audioSettings.js`; огибающая остаётся плавной и при перекрытии голосов.
