# Sacura Novel Studio — UI prototype 04

Локальный макет редактора 3D-визуальных новелл и point-and-click. React, React Flow и Three.js здесь нужны для проверки интерфейса; это не реализация будущего C++-движка.

## Запуск

```powershell
cd engine-react-template
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

Открыть http://127.0.0.1:5173/. Если сервер уже работает, второй запуск не нужен.

## Рабочая область

- **В центре — сцена.** Разделитель между сценой и графом перетаскивается мышью. Боковые панели тоже меняют ширину. Двойной клик по разделителю возвращает размер. Кнопка разворота есть у сцены и графа.
- **Сцена / Игра.** В сцене ЛКМ выделяет объект, Alt+ЛКМ вращает камеру, СКМ сдвигает обзор, ПКМ+WASD/QE включает свободный полёт (Shift ускоряет); игра использует постановочную камеру. Диалог и ответы находятся внутри игрового кадра. Переключение режима, выделение и resize не перезапускают проигрывание.
- **Слева — Иерархия / История.** Объекты, поиск реплик, эпизоды и сабсцены. Поиск раскрывает эпизоды. Выбор реплики показывает её свойства и граф.
- **Под сценой — Сценарий / Постановка / Событие.** Три уровня одной истории: переходы между репликами; события до, во время и после текста; группы и Actions внутри события.
- **Справа — Инспектор.** Свойства выделенного объекта или узла. Основные параметры Action также редактируются прямо на графе. «Все параметры рядом» открывает большой редактор в центральной области.
- **Проект, Звук, Активные, Ошибки** доступны вкладками той же нижней панели.

## Изменения 04

- **Сабсцены** — отдельная карта настоящих межсценовых связей, возвратов и концовок. Под картой видны источник, ответ, условие и точная реплика назначения. Нажатие на переход открывает его в сценарии.
- **Эффекты** — 30 примеров: дождь, гроза с молнией, туман, снег, ясное небо, время суток, свет, движение, позы, камера, дверь, предметы, светлячки и лепестки. «Проба» применяет событие в 3D, «Граф» открывает структуру, «В реплику» добавляет реальное размещение. «Проиграть постановку» соединяет четыре последовательные группы с параллельными действиями внутри.
- Игровые камеры находятся внутри гостиной, сада и станции. При ожидании предмета камера показывает его крупнее; записка/письмо имеют линии, печать и подпись осмотра. Декорации не перекрывают записку на скамье.
- Продолжить можно кликом по всей карточке диалога или свободной области сцены. Выбор ответа и ожидание предмета таким кликом не пропускаются.
- Погода и время переключаются прямо в правом верхнем углу сцены. В playtest это временное изменение; вне проигрывания — начальное состояние выбранной сабсцены.
- Звук использует общий Web Audio output, разблокируемый кликом запуска. Очень тихие записи усиливаются при воспроизведении с ограничением по пику; исходные файлы сохранены. Уровень выхода виден под сценой. Ошибки файлов видны в пульте.
- События показывают в сцене тип действия, цель, применение и прогресс движения. Повторная проба не разрешает незаметно запустить два Move одного персонажа. Пробы работают отдельно от сюжета; «Стоп» возвращает редактор.

## Что попробовать

1. На первой реплике открыть **До реплики**. Музыка и дождь стартуют вместе, результаты сходятся, затем меняется камера. В этой же реплике есть параллельные события во время текста и последовательные действия после него.
2. Переключить **Вместе / По очереди** на группе в графе. Кнопка `+` добавляет событие в эту группу; шестерёнка открывает порядок и состав. Соседние группы можно объединить для одновременного запуска.
3. Открыть действия события. Перемещение предлагает объект и точку; погода и время — состояния; звук — файл и громкость. У размещённого события параметры меняют только его экземпляр. Состав групп редактируется в исходном шаблоне.
4. Открыть «Письмо на столе» → «Что сказать Бобу?». **Обзор развилки** показывает ближайшие разные продолжения. Выходы ответов соединяются мышью; обычные связи тоже можно переназначать. В инспекторе ответа задаётся условие и конкретная реплика назначения.
5. Запустить с этой развилки и выбрать **Спрятать письмо**: `ls1 → ls2 → ls3 → station-entry`. Другая ветка ведёт в сад. На станции выбор возвращения домой недоступен без письма, а билет требует клика по объекту в 3D.
6. Запустить с начала: WAV и три MP3 используются как фоновая тема и голоса первых трёх реплик. Вкладка **Звук** позволяет прослушать файлы, менять громкость, loop, fade и привязывать звук к реплике. Волны извлекаются из самих файлов.
7. Открыть **Активные**. Эффекты и экземпляры показывают состояние, источник и границу жизни. Можно приостановить эффект или завершить событие целиком. Пауза экземпляра приостанавливает его конечные действия; остановка отменяет последующие группы.
8. Открыть **Ошибки**: в `l3` намеренно сталкиваются два Move Алисы; в `t1` два события ждут друг друга. Есть переход к проблеме и исправление. Лаборатория сбоев показывает частичный запуск, исчезновение объекта, устаревший экземпляр, ошибку cleanup и выход из сабсцены.

## Сохранение

Проект сохраняется в `localStorage/sacura-studio-v2`; раскладка и координаты узлов — отдельно в `sacura-workspace-v3`. Пользовательские шаблоны и данные прежней версии сохраняются. Перед миграцией v1 остаётся резервная копия `sacura-ui-project-v1-backup`.

Меню **Файл**: экспорт и импорт JSON. Перед импортом создаётся резервная копия текущего проекта `sacura-studio-v2-backup-v3`. **Правка / Ctrl+Z** отменяет до 20 последних изменений текущей сессии. `Ctrl+S` подтверждает локальное сохранение. При ошибке чтения сохранение не перезаписывается.

Изменения содержания во время проигрывания используются в следующем запуске. Текущий playtest работает со снимком проекта.

Основной вход — `src/Editor.jsx`. `Studio.jsx` и старые экраны оставлены в исходниках для сравнения.

## Проверки и пределы

`npm test`: автоматические проверки порядка фаз, параллельных запусков, ожидания аудио, ветвлений, миграции, локальных переопределений, конфликтов, паузы/отмены экземпляра и отмены поздних действий. `npm run build` проходит.

Проведена браузерная проверка: внешний вид в обычном окне и при 1440×900, resize мышью, сохранение диалога при выборе объекта и смене режима, первые три озвученные реплики, отдельная ветка до станции, условный ответ, клик по билету, смена порядка группы, открытие Action, вставка вложенного выбора с сохранением продолжения и переназначение связи с отменой. Для каждого из четырёх файлов проверены запуск и ненулевой сигнал Web Audio на выходе. Оценка звучания человеком не проводилась.

Это ограниченный планировщик предпросмотра. Перемещение плавно интерполирует позицию в течение указанной длительности, учитывает паузу и остановку. Погода и время меняют частицы, туман, цвет неба и освещение; сложной физической симуляции нет. Арбитр ресурсов, очереди, подтверждённый cleanup, AI/NPC и универсальное ожидание результатов других событий представлены диагностикой и настройками, а не производственным C++-runtime. Для ожидания действия игрока используется отдельный блок взаимодействия. Статическая проверка не доказывает корректность всех возможных графов и межрепличных пересечений.

Основания дизайна и расхождения: [DESIGN-NOTES.md](DESIGN-NOTES.md).


## Создание действий, групп и событий

Кнопка **«Действия и события»** в верхнем меню открывает большую рабочую область. Тот же редактор доступен во вкладке **«Создание»**. Вверху всегда видны три кнопки: **+ Действие**, **+ Группа действий**, **+ Событие**.

1. Создайте действие, дайте название, выберите тип и настройте объект, звук или окружение. Нажмите **«Сохранить в библиотеку»**.
2. Из действия можно сразу **создать событие**. Внутри шага добавляйте параллельные действия из библиотеки или по типу; **«Добавить следующий шаг»** создаёт последовательность. Группы тоже сохраняются отдельно.
3. **«Проверить в сцене»** запускает отдельное превью текущего черновика. **«В реплику»** добавляет сохранённое событие в текущую реплику с явным выбором «до / во время / после».
4. Готовые события доступны и в графе. При повторном открытии чистый редактор получает актуальные изменения из графа. Несохранённые черновики доступны в списке библиотеки, пока приложение открыто.

Действия и группы вставляются как независимые копии с новыми ID. Изменение шаблона события применяется к его размещениям; локальные переопределения сохраняются. Пустые шаги, конфликтующие параллельные команды и незаданная роль замены показывают ошибку до сохранения.

## Редактирование 3D-сцены

Нажмите **«Редактор сцены»** над 3D-кадром. Воспроизведение остановится, чтобы редактировать исходную постановку. Выберите персонажа, мебель или предмет в сцене либо в иерархии.

- **W / Сдвиг**, **E / Поворот**, **R / Масштаб** — перетаскивание цветных осей. **Q** — выбор без манипулятора; **F** — приблизить объект. Клавиши работают, когда фокус находится в сцене.
- В инспекторе доступны XYZ, поворот в градусах, масштаб, сброс, дубликат и удаление. Изменение числового поля применяется по Enter или потере фокуса. Ctrl+Z отменяет редактирование.
- **«+ Объект»** добавляет персонажа, интерактивный предмет, куб, сферу или цилиндр. Форма простого меша и цвет меняются в инспекторе.
- Магнит включает привязку 0,25 м / 15° / 0,1×. Оси можно переключать между миром и объектом.
- Размещение хранится отдельно для каждой сабсцены и сохраняется в JSON/локальном проекте. Перенос записки учитывается камерой взаимодействия; события движения начинают путь из авторской позиции.

В макете редактируются объекты и собранная из примитивов мебель. Стены, пол, потолок, окно, лампа, деревья, дорожка, платформа, рельсы и навес также доступны в иерархии и редактируются как объекты. Составные предметы перемещаются целиком; это не редактор полигональной геометрии.


## Камеры и слежение

Над 3D-сценой появилась кнопка **«Камеры»**. Камеры также видны в иерархии сабсцены.

- **Камера из вида** сохраняет тот ракурс, который сейчас виден в 3D. Поверните свободный обзор мышью, сдвиньте его правой кнопкой, приблизьте колесом — затем создайте камеру.
- **Настроить ракурс мышью** открывает кадр выбранной камеры. Найдите композицию и нажмите **«Сохранить ракурс»** над сценой. Крестик вернёт свободный обзор без сохранения. Угол обзора задаётся ползунком.
- В свободном редакторе камеры обозначены розовыми 3D-маркерами. Выбранную камеру можно перемещать и поворачивать стандартными манипуляторами. Контур показывает направление и границы кадра.
- **Следить за персонажем** создаёт основную следящую камеру. В настройках выберите героя, расстояние, высоту, ракурс вокруг него и плавность. Камера сопровождает интерполированное движение; при переносе камеры манипулятором сохраняет взгляд на герое. Режим можно переключить и у существующей камеры.
- **Посмотреть** показывает выбранную камеру, **По сценарию** возвращает автоматическое управление. Основная камера используется для «Общего плана». В действии **«Сменить план»** можно выбрать конкретную сохранённую камеру, включая следящую.

При обязательном осмотре предмета сценарий временно показывает предмет, затем возвращает следящую камеру. Явное действие переключения на другой план меняет камеру. Если персонаж скрыт или удалён, сохраняется запасной неподвижный кадр и появляется сообщение в настройках камеры. Камеры сохраняются отдельно по сабсценам, поддерживают Undo и экспорт проекта.

## Добавление и редактирование сабсцен

Откройте вкладку **«Сабсцены»** под 3D-кадром. Здесь три представления: **Редактор**, **Переходы**, **Карта**. Сабсцену также можно выбрать в левом списке или открыть кнопкой «Сабсцена» над инспектором.

- **«Добавить сабсцену»** (либо «+» в списке / «Создать → Сабсцена») открывает большую форму. Укажите название, выберите гостиную, сад или станцию, персонажей, окружение и первую реплику. Камера и предметы локации создаются автоматически.
- Новую сабсцену можно оставить отдельной или вставить после текущей реплики / конкретного ответа. При вставке прежнее продолжение сохраняется после новой сабсцены.
- В редакторе меняются название, заметка, локация, время, погода, состав персонажей и начальная реплика. Есть прямые кнопки сценария, редактирования 3D и камер. Изменения сохраняются автоматически, Ctrl+Z отменяет их.
- **«Переходы»** показывает входящие и исходящие связи и позволяет выбрать исходную реплику или ответ, найти его по тексту и назначить сабсцену назначения. Условия ответов сохраняются. При изменении начальной реплики можно перенаправить входы со старого начала; прямые переходы на другие реплики сохраняются.
- **«Дублировать»** копирует сценарий, локальные объекты и камеры с новыми ID. Внутренние связи переводятся на копию; внешние выходы и библиотечные шаблоны событий остаются общими. Размещения персонажей независимы, определения общих персонажей сохраняются.

Смена шаблона локации сохраняет сценарий и авторские объекты. Если событие или ожидание осталось привязано к недоступному предмету, вкладка «Ошибки» показывает проблему. Геометрия ограничена тремя шаблонами этого макета.


## Иерархия, навигация и общий таймлайн

- Стрелки у сабсцены, камер, объектов и точек сворачивают и разворачивают группы. Кнопки над деревом открывают или закрывают все группы; состояние сохраняется отдельно для каждой сабсцены. Двойной щелчок по объекту показывает его в кадре.
- У иерархии и инспектора есть кнопки сворачивания и разворота. Свёрнутая панель восстанавливается боковой кнопкой; меню **Окно** также открывает панели. Разворот сцены или рабочей области занимает всё доступное место. **Escape** возвращает обычную раскладку.
- Управление 3D по образцу Unity: **ЛКМ** — выбор, **Alt+ЛКМ** — орбита, **СКМ** — панорама, **ПКМ + WASD** — полёт, **Q/E при зажатой ПКМ** — вниз/вверх, **Shift** — ускорение, **колесо** — приближение. Вне полёта **W/E/R** выбирают перемещение/поворот/масштаб, **F** показывает выделенное в кадре.
- **Точки постановки** принадлежат своей сабсцене: у гостиной, сада и станции разные названия и привязки. Щелчок показывает связанный предмет; точки следуют за его перемещением. В инспекторе команда **Опорная точка** переносит выбранный объект к точке. Копии сабсцен получают независимые точки.
- Вкладка **Таймлайн** и **Окно → Общий таймлайн** открывают всю историю отдельно от редактора реплик. На графе показаны сабсцены, реальные выборы и условия, возвраты и концовки. Линейные реплики объединены во фрагменты; дополнительные входы в сабсцену сохраняются. Кнопки **Текущий узел** и **Вся история** управляют обзором. Щелчок по глобальной переменной показывает её зависимости; значения отражают текущий playtest.
- Список выбора сабсцены использует палитру редактора и поддерживает стрелки клавиатуры, Enter и Escape.

## Множественное выделение и расположение узлов

**Shift + щелчок** в сцене или иерархии добавляет объект к выделению; повторный щелчок с Shift убирает его. Выделение общее для обеих панелей. Манипулятор перемещает, вращает и масштабирует всю группу; **F** показывает все выбранные объекты. В групповом инспекторе можно применить относительную трансформацию, сбросить положение, создать дубликаты или удалить выделенное. Одна групповая операция отменяется одним **Ctrl+Z**.

Карточки во вкладке **Таймлайн**, включая глобальные переменные, можно перетаскивать за заголовок или текст. Соединения следуют за карточками, маршруты истории не меняются. Координаты сохраняются в проекте; **Ctrl+Z** отменяет перенос, **Автораскладка** возвращает автоматическое расположение. Двойной щелчок или кнопка **Сценарий** открывает исходную реплику.

## Настройки сайдчейна

Во вкладке **Звук → Сайдчейн проекта** доступны атака, восстановление (release) и снижение громкости в dB. Диапазоны: 0,05–10 секунд и 0–24 dB; 0 dB отключает приглушение. Значения по умолчанию — 0,6 с / 0,9 с / 4 dB. Изменения сразу применяются к прослушиванию и Playtest с плавным переходом и сохраняются вместе с проектом.

## Сохранение, новые проекты и шаблоны

- **Файл → Сохранить проект** (**Ctrl+S**) записывает JSON проекта. Если файл ещё не выбран, открывается системное окно сохранения. Последующие сохранения в этой сессии используют тот же файл. В браузерах без доступа к выбору файла проект передаётся в загрузки. Автосохранение рабочего проекта в браузере продолжает работать отдельно.
- **Сохранить проект как…** (**Ctrl+Shift+S**) создаёт копию под новым названием и делает её текущей после успешной записи. Отмена выбора файла оставляет текущий проект без изменений.
- **Новый пустой проект…** создаёт одну пустую сцену с камерой и начальной строкой сценария, без моделей и демонстрационных событий. В этом же окне можно выбрать сохранённый шаблон.
- **Записать проект как шаблон…** сохраняет независимый снимок в библиотеке этого браузера. **Экспортировать шаблон…** выгружает переносимый `.sacura-template.json`; его можно открыть через **Открыть проект…**, чтобы создать отдельный проект.
- **Восстановить предыдущий проект** возвращает резервную копию, сделанную перед созданием, открытием или сохранением копии проекта. Хранится один предыдущий проект.

Файлы проекта и шаблоны сохраняют сцены, объекты, события, параметры звука и ручное расположение узлов таймлайна. Доступ к выбранному файлу действует до перезагрузки страницы; после неё файл нужно выбрать снова.
