# Sacura Desktop Experiment

Отдельная Electron оболочка существующего React редактора. C++ Engine и Qt Editor не участвуют.

Из `desktop-electron/`:

```powershell
npm install
npm --prefix ../engine-web-prototype/frontend install
npm run desktop:dev
```

Vite запускается на `127.0.0.1:5173`; Electron открывается после готовности Vite. Изменения React обновляются через HMR. Закрытие Electron завершает дочерний Vite.

Сборка без сервера:

```powershell
npm run desktop:build
```

Результат в `release/win-unpacked/Sacura Desktop Experiment.exe` на Windows. Внутри пакета лежит локальная Vite сборка, открываемая через внутренний протокол `sacura://`; интернет и backend для запуска не нужны.

Проверка без UI automation: `npm test` проверяет запись и повторное открытие проекта; `npm run smoke:editor` запускает упакованное приложение с временным проектом и ждёт сигнала монтирования редактора. `npm run smoke:hmr` проверяет обновление JSX модуля через Vite без пересборки Electron. `npm run desktop:dev -- --desktop-smoke` проверяет development запуск.

При первом запуске создайте проект и выберите родительскую папку. Получится `<папка>/<имя>/project.json`, каталоги `Assets/{Models,Textures,Audio,Files}` и `Stories`. «Открыть папку проекта» открывает существующий `project.json`. Последний проект открывается при следующем запуске. Файл → Сохранить записывает текущий проект; Файл → Сохранить как создаёт копию в выбранной родительской папке. Импорт файлов в проводнике ресурсов и звуковой панели использует системный выбор через Electron main process; импорт папки и drag-and-drop используют пользовательский выбор файлов Chromium. При сохранении встроенные PNG/GLB/аудио выносятся в `Assets` и в JSON остаются относительные пути.

Ограничения эксперимента: `project.json` сохраняет формат React редактора v1/v2, а не C++ `.project`/`.scene`; C++ renderer и Python gameplay не подключены. Встроенные ассеты шаблонов остаются ресурсами приложения. Модели OBJ, некоторые экспорты и пользовательские пакеты могут оставлять данные внутри JSON; полная миграция всех ссылок на файлы в эту версию не входит. Текущий редактор использует Three.js.
