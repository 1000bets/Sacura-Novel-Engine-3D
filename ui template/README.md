# Sacura Studio · UI/UX prototype 02

Локальный интерактивный макет на React + Vite + Three.js. Проверяет интерфейс редактора 3D-новелл и point & click. Будущий C++-движок здесь не реализуется.

## Запуск

```powershell
cd 'F:\projects\Sacura-Novel-Engine-3D\ui template'
npm install
npm run dev -- --port 5173
```

Открыть [локальный макет](http://127.0.0.1:5173/). Также доступен `start.cmd`.

## Что попробовать

1. **Постановка → Возвращение → первая реплика.** Три колонки: «До», «Во время», «После». До текста музыка и дождь стартуют одновременно, затем переключается камера. Во время текста вместе звучит рассказчик и входит Алиса. После продолжения идут остановка Алисы и наступление ночи.
2. **Запустить отсюда.** Подсветка отражает выполнение. Текст появляется после BEFORE. Во время озвучки музыка приглушается. Продолжение ждёт готовности действий; AFTER запускается после нажатия.
3. **Нажать карточку события.** Большой редактор в основной области показывает все группы и Actions, стрелки, соединения и параметры. Настройки размещения отличаются от шаблона. «Открыть шаблон» явно меняет контекст редактирования.
4. **Звук.** Четыре MP3: воспроизведение, пауза, продолжение, остановка, громкость, повтор, плавный вход, перемотка по волне. «В реплику» добавляет настроенный файл в выбранную постановку.
5. **Продолжается в фоне.** Постоянный пульт музыки, погоды, времени суток и дополнительных удерживаемых событий: источник, состояние, пауза, продолжение, завершение. В редактировании погода/время задают начальное состояние сабсцены; во время Preview меняют пробное состояние.
6. **Карта истории → «Что сказать Бобу?»** Спрятать письмо → другой разговор → станция. Спросить о матери → вложенная развилка → сад. Рассказать правду → чтение письма и домашняя линия. Выходы редактируются, Preview использует эти же связи.
7. **Сад / станция.** Переход меняет 3D-примитивы локации. В саду осматривается записка, на станции предъявляется билет. Пока взаимодействие не выполнено, история ждёт. Таймер даёт подсказку, а не пропускает игрока автоматически.
8. **Проверка проекта.** Намеренные проблемы: `l3` — два Move Алисы одновременно; `t1` — события ждут друг друга. Исправления меняют данные и отменяются кнопкой сверху. Корректные реплики запускаются сразу. Ниже находится UX-лаборатория пяти асинхронных сбоев.

## Создание

- В каждой фазе: следующий шаг, событие в существующий шаг, смена последовательности/параллельности, перенос в отдельный шаг, перемещение и удаление.
- В событии: последовательные группы и параллельные Actions. Группу можно превратить в отдельное переиспользуемое событие.
- Тип блока выбирается в карточке реплики: текст, выбор, ожидание, схождение, концовка. На карте добавляются ответы, условия, пороги доверия и продолжения.
- «Объекты» создаёт персонажей, активные меши и декорации. Объект можно связать с ожиданием игрока.
- Плюс рядом с «Сабсцены» создаёт сабсцену и первую реплику. Ниже постановки выбираются название локации и примитивы превью.
- «Все реплики» ищет по всей истории, включая другие локации и вложенные ветви.

## Демонстрационный проект

**105 блоков, 82 обычные реплики, 13 развилок, 3 концовки, 3 сабсцены, 8 эпизодов, 26 шаблонов, 69 размещений, 7 объектов.** Некоторые старые точки схождения оставлены доступными для переназначения.

| MP3 из public/sound | Назначение | Длительность |
|---|---|---:|
| MainMenuSound.mp3 | Фоновая тема, stereo | 4:00 |
| The_house_greeted_her_with_the_scent_of_wet_wood.mp3 | Рассказчик, реплика 1 | 2,69 сек. |
| You_came_back_after_all.mp3 | Боб, реплика 2 | 1,38 сек. |
| I_promised_return_before_rain_goes.mp3 | Алиса, реплика 3 | 2,17 сек. |

Волны извлекаются из файлов через Web Audio, время берётся у аудиоэлемента. Музыка приглушается на 12 dB, пока играет голос, и возвращается к установленной громкости после паузы, окончания или остановки озвучки.

## Сохранение

Автосохранение: localStorage `sacura-studio-v2`. При первом переходе с v1 исходный JSON копируется в `sacura-ui-project-v1-backup`; сам ключ v1 не меняется. Пользовательские шаблоны, объекты, дополнительные поля, явные переходы и локальные параметры сохраняются. Начальная демонстрационная постановка дополнена звуком и локациями.

Импорт и экспорт JSON — справа вверху. Перед импортом текущий проект копируется в `sacura-studio-v2-before-import`. Кнопка отмены хранит 15 последних состояний текущей сессии. При ошибке чтения исходное сохранение не перезаписывается. Старые App.jsx и стили оставлены для сравнения; основной вход теперь использует Studio.jsx.

## Проверки и пределы

`npm test`: 27 проверок — порядок фаз, ожидание звука в модели, параллельные запуски, граф/концовки, миграция, локальные конфликты, пересечение фаз, отмена поздних работ и восстановление громкости. `npm run build` проходит. Проверены серверная генерация разметки первого экрана, HTTP-доступность MP3 и формат/длительность через ffprobe. В этой итерации браузерный визуальный и слуховой проход не выполнялся.

Это ограниченный планировщик предпросмотра. Движение меняет позицию после заданной длительности. Погода и время — управляемые состояния без полноценной климатической симуляции. Шаги, камин и шум дождя пока без аудиофайлов. Очереди, атомарный захват ресурсов, подтверждённый cleanup и интеграция подсистем представлены настройками и лабораторией поведения; производственного арбитра ресурсов нет. Произвольные графы и межрепличные пересечения не считаются полностью доказанными статически. Пульт показывает текущие эффекты одной сцены и одну музыкальную шину.
